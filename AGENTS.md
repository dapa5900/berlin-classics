# Berlin Classics Newsletter

## Commands (Windows)

```powershell
venv\Scripts\activate.ps1        # activate venv
pytest tests/                    # 39 sync tests, no external deps
ruff check .                     # lint
```

## Run modes

| Command | Effect |
|---|---|
| `run_process.bat` | Normal: cache → scrape missing → TMDB → newsletter |
| `run_fresh.bat` | `--no-cache`: fresh scrape all sites |
| `run_cached.bat` | `--fast`: skip TMDB, re-apply title/year filters (instant, for template/config tweaks) |
| `run_babylon.bat` | Rescrape only Babylon, rest from cache |
| `run_zoo_palast.bat` | Rescrape only Zoo Palast |
| `run_bestofcinema.bat` | Rescrape only Best of Cinema |
| `run_openair.bat` | Rescrape only Open Air Kino |

All `.bat` launchers delegate to `scripts\run_timed.bat` which activates venv, passes args to `main.py`, and prints elapsed time.

**`--re-enrich`**: clears TMDB memory cache, re-runs TMDB on raw cache — use when `_clean_title` patterns change.

## Pipeline (two-level cache)

```
scrape → cache/screenings.json → title filters → TMDB enrich → filter_no_tmdb → cache/screenings_enriched.json → year filter → newsletter
```

- **Raw cache** (`cache/screenings.json`): scraper output before TMDB. Saved on every scrape run.
- **Rich cache** (`cache/screenings_enriched.json`): after TMDB, before year/title filters. Generated by normal runs (not `--fast`).

## Architecture

- `main.py:39-44` maps config `type` → scraper class. All scrapers return raw `Screening` (no TMDB).
- `Screening` dataclass (`scrapers/base.py:11-24`): `cinema_name`, `movie_title`, `date`, `url`, `year`, `poster_url`, `tmdb_url`, `skip_year_filter`, `runtime`, `venue_name`, `production_year`, `original_title`
- TMDB enrichment (`main.py:71-111`) groups by `(movie_title, production_year, original_title)`, queries once per group, mutates `Screening` in place
- `_clean_title` (`services/tmdb.py:52-87`): NFD-normalizes, strips known series/festival prefixes via regex. Add new patterns here for obscure titles that fail TMDB match.
- Also handles multi-part titles (`_is_multi_part_title`, `_extract_base_title`) for "trilogie"/"marathon"/"X-hour" patterns
- Template groups by `venue_name` if set, else `cinema_name` (`templates/newsletter.html:475`). Open Air Kino sets `venue_name` per-article; all others leave `None`.
- Config-driven via `config.yaml`: cinemas, title filters, year threshold, output format

## Scraper gotchas

- **Babylon**: HTTP GET to `/programm`. Each `.mix` `<li>` has `cat-*` CSS class. `_strip_festival_prefix` auto-detects festival sections (URL contains `/festivals/`) and strips the festival prefix. Uses `.right-mix .mix-title` (full title), `.mix-introtext` (year via `,\s*(\d{4})`, original via `[...]` brackets), `.right-mix .runtime`.
- **Zoo Palast**: Playwright-based. Intercepts API JSON from `premiumkino.de/program` via network listener. Also scrapes `/specials/filmklassiker` to set `skip_year_filter=True`.
- **Best of Cinema**: Fetches each movie subpage individually. `Produktionsjahr:` and `Laufflänge` regex from page text.
- **Open Air Kino**: Date in `div.meta_kino` previous sibling of `<article>`, uses `[\w.]+` for abbreviated German months. Multi-cinema aggregator — `venue_name` set per screening.

## TMDB matching order (`services/tmdb.py`)

1. Prioritized: if `original_title` + `expected_year`, search original title + exact year match first
2. Exact year match
3. ±3yr, similarity ≥ 0.3
4. ±2yr, similarity ≥ 0.5
5. Best similarity fallback (≥0.7, best year diff)

## Config (`config.yaml`)

- `classical_year_threshold`: year ≤ this passes filter (default: 2010), unless `skip_year_filter=True`
- `title_filters`: per-cinema list; screenings with matching substring in `movie_title` are excluded
- `output.filename_template`: `newsletter_{date}.html`

## File structure

```
main.py               # entrypoint — CLI, pipeline orchestration
config.yaml           # cinema definitions, filters, year threshold
scrapers/
  base.py             # Screening dataclass, BaseScraper with rate limiting
  babylon.py / zoo_palast.py / bestofcinema.py / openair_kino.py
services/
  tmdb.py             # TMDB API queries, title cleaning, matching logic
  newsletter.py       # Jinja2 rendering (locale: de_DE.UTF-8 at module level)
templates/
  newsletter.html     # single Jinja2 template
tests/                # 4 test files, 39 tests — sync, no deps
scripts/
  run_timed.bat       # shared launcher (activate venv → python main.py %*)
  setup_scheduler.bat # creates Windows Task Scheduler entry
  unscheduler.bat     # removes it
deploy.bat            # copy → commit → push to GitHub Pages
cache/                # gitignored — raw + enriched screening JSON
output/               # gitignored — generated HTML newsletters
docs/                 # git tracked — index.html served by GitHub Pages
```
