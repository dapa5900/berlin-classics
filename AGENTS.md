# Berlin Classics Newsletter

## Commands (Windows)

```powershell
venv\Scripts\activate.ps1  # activate venv
pytest tests/               # 39 tests, sync, no external deps
ruff check .                # lint
```

All `.bat` launchers delegate to `scripts\run_timed.bat` which passes args to `main.py` and shows elapsed time.

| Run... | Flag | Use case |
|---|---|---|
| `run_fresh.bat` | `--no-cache` | Fresh scrape from all cinema sites |
| `run_process.bat` | *(none)* | Normal run: cache → scrape missing → TMDB → newsletter |
| `run_cached.bat` | `--fast` | Skip TMDB, re-apply title/year filters (instant) |
| `run_babylon.bat` | `--cinema babylon` | Rescrape only Babylon, load rest from cache |
| `run_zoo_palast.bat` | `--cinema zoo_palast` | Rescrape only Zoo Palast |
| `run_bestofcinema.bat` | `--cinema bestofcinema` | Rescrape only Best of Cinema |
| `run_openair.bat` | `--cinema openair_kino` | Rescrape only Open Air Kino |

## Pipeline (two-level cache)

```
scrape → raw cache → title filters → TMDB enrich → filter_no_tmdb → enriched cache → year filter → newsletter
```

- **Raw cache** (`cache/screenings.json`): scraper output before TMDB. Saved on every scrape run.
- **Rich cache** (`cache/screenings_enriched.json`): after TMDB + `filter_no_tmdb`, BEFORE year/title filters. Generated by normal runs (not `--fast`).

`--fast` loads rich cache, re-applies title + year filters. Great for template/config tweaks.
**Caveat:** relaxing a title filter (letting more movies through) requires re-running without `--fast` — rich cache was saved with old filter results.

`--cinema X` loads other cinemas from cache, only scrapes `X` fresh.
`--re-enrich` clears TMDB memory cache and re-runs TMDB on raw cache — useful when `_clean_title` patterns change.

## Architecture

- `main.py:39-44` maps config `type` → scraper class. All return raw `Screening` (no TMDB).
- TMDB enrichment (`main.py:72-102`) groups by `(movie_title, production_year, original_title)`, queries TMDB once per group, mutates `Screening` in place.
- `_clean_title` (`services/tmdb.py:52-87`): NFD-normalizes, strips known series/festival prefixes via regex. Add new patterns here for obscure titles that fail TMDB match.
- Template groups by `venue_name if venue_name else cinema_name` (`templates/newsletter.html:475`). Open Air Kino sets `venue_name` per-article; all others leave it `None`.

## Scraper gotchas

- **Babylon**: Single HTTP GET to `/programm`. Each `.mix` `<li>` has a `cat-*` CSS class identifying its section. `_strip_festival_prefix` (`babylon.py:16-49`) auto-detects festival sections (URL contains `/festivals/`) and strips the festival prefix from `movie_title` before creating `Screening`. Explicit override at `babylon.py:11-13` for `cat-DEFA-80` → `"80 Jahre DEFA: "` (display name mismatch). Uses `.right-mix .mix-title` (full title), `.mix-introtext` (year via `,\s*(\d{4})`, original title via `[...]` brackets), `.right-mix .runtime`.
- **Zoo Palast**: Playwright-based. Intercepts API JSON from `premiumkino.de/program` via network listener. Also scrapes `/specials/filmklassiker` to set `skip_year_filter=True` on klassiker entries.
- **Best of Cinema**: Fetches each movie subpage individually. `Produktionsjahr:` and `Laufflänge` regex from page text.
- **Open Air Kino**: Date in `div.meta_kino` previous sibling of each `<article>`, uses `[\w.]+` for abbreviated German months. Multi-cinema aggregator — `venue_name` set per screening.

## TMDB matching order (`services/tmdb.py`)

1. Prioritized: if `original_title` + `expected_year` provided, search original title + exact year match first
2. Exact year match
3. ±3yr, similarity ≥ 0.3
4. ±2yr, similarity ≥ 0.5
5. Best similarity fallback (≥0.7, best year diff)
